# Vibe Warehouse — Portfolio Evidence Host

Curated public artifacts used by the Vibe Warehouse product-design portfolio.

## Published artifact

- `tech-tree/latest/` — interactive Technology Tree portfolio prototype.

## Evidence boundary

The Technology Tree artifact is a prototype, not a final production UI. Dependency routing remains under active iteration, especially same-Era and long-span connectors. Icon presentation is also prototype-level and replaceable.

The public repository intentionally contains only portfolio-safe artifacts. It is not the source repository for the Vibe Warehouse game.
